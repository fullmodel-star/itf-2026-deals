# 2026 ITF 台灣國際旅展 優惠整理

展期 2026/11/6–11/9，南港展覽館 1 館。資料查詢日期 2026-10-29。

**網頁版：** https://fullmodel-star.github.io/itf-2026-deals/

可以搜尋、篩選、排序；點任一筆會展開完整資料、來源網址和截圖。

| 資料夾 | 內容 |

每個資料夾有一個 `.csv` 資料表（Excel 可直接開）、一份分析文件和 `截圖_jpg`。
重點整理在 [_先看這裡_總表.md](_先看這裡_總表.md)。

## 更新資料

1. 修改各資料夾的 `.csv`（新增、修改價格都可以）。
2. 有新截圖就放進該資料夾的 `截圖\`，再執行 `python _工具/shrink_shots.py` 壓成 JPG。
3. 執行 `python _工具/build.py` 重新產生 `index.html`。
4. commit 並 push，網頁版幾分鐘內就會更新。

也可以直接請 Claude 做以上步驟。

## 說明

- 價格整理自各飯店、航空、旅行社官網及新聞報導，實際以商家公告為準。
- 標「2025參考」的是去年的旅展價格，已經過期。
- 不同來源說法不一樣的，兩邊都記在備註欄。
